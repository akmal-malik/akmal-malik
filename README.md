## 🚀 Featured Projects

### 🏥 HERA – Healthcare and Emergency Resource Analytics

A healthcare-focused intelligence project designed to support blood inventory monitoring, expiry management, and data-driven resource analysis.

**Key Contributions:**

- Developed a Streamlit-based Blood Bank Intelligence System to monitor inventory, track blood bag expiry, and support efficient resource management.
- Applied C++ Priority Queues and Unordered Maps to manage blood bag records and prioritize units approaching expiration.
- Generated and analyzed a **14,000-record synthetic dataset**, using research literature as a reference to identify blood inventory shortages, surpluses, and distribution imbalances across hospitals.
- Benchmarked Linear Regression, Random Forest, and XGBoost models, identifying Random Forest as the best-performing model.
- Integrated the Streamlit application with MySQL to persist inventory transactions and application updates.

**Tech Stack:** Python, C++, Streamlit, MySQL, Scikit-learn, Pandas, NumPy, Matplotlib.

### 🤖 ResumeIQ AI – AI-Powered Resume Screening & ATS Platform

An AI-powered resume screening platform that analyzes resumes against job descriptions using NLP-based semantic matching and provides users with a dashboard to track their resume analysis history.

**Key Contributions:**

- Built a resume screening platform using React and FastAPI, with PostgreSQL for data storage.
- Applied Sentence Transformers (`all-MiniLM-L6-v2`) for semantic matching between resumes and job descriptions.
- Developed PDF and DOCX document-processing functionality using pdfplumber and python-docx.
- Integrated SQLAlchemy-based database operations and JWT authentication.
- Designed an interactive analytics dashboard to display previous resume analyses, recent activity, and ATS score trends to track resume improvements over time.

**Tech Stack:** React, Tailwind CSS, Python, FastAPI, PostgreSQL, SQLAlchemy, JWT, Sentence Transformers, pdfplumber, python-docx.

### 🎁 GiveYu – Privacy-First Digital Gifting Platform

🌐 **Live Website:** [giveyu.com](https://giveyu.com)

A lightweight digital gifting platform that allows friends and couples to exchange personalized digital gifts through shareable links without account registration or application-side data storage.

**Key Contributions:**

- Built the complete platform using HTML, CSS, Tailwind CSS, and JavaScript.
- Leveraged LZ-String compression to encode and decode gift messages and sender/recipient details directly within shareable URLs.
- Designed a browser-based workflow that processes gift data without requiring an application database or user accounts.
- Managed production hosting through Hostinger and DNS protection through Cloudflare.
- Managed the migration from `.online` to `.com`, updating canonical URLs, XML sitemaps, robots.txt, and HTTP headers.
- Resolved post-migration indexing issues through Google Search Console, restoring Google search visibility across the website's pages.

**Impact:**

- 🌍 20,000+ user interactions globally.
- ⚡ Over 1 million HTTPS requests since launch.
- 🔎 Successfully recovered Google search indexing following the domain migration.

**Tech Stack:** HTML, CSS, Tailwind CSS, JavaScript, LZ-String, Hostinger, Cloudflare, Google Search Console, Technical SEO.
